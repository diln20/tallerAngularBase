# Taller Angular Base

Taller práctico del proyecto **Gestor de estudiantes**, construido paso a paso desde la creación del proyecto Angular.

## Recorrido

1. Crear el proyecto con `ng new`
2. Estructura de archivos y `app-root`
3. Data Binding
4. Arrays y `@for`
5. `@if` y booleanos
6. Eventos y cambio de estado
7. Eliminar y usar `id`
8. Formularios con `FormsModule` y `ngModel`
9. Validaciones
10. Edición y CRUD
11. Crear `TarjetaEstudiante`
12. Padre → Hijo con `input()`
13. Hijo → Padre con `output()`
14. `id`, `$event`, `find()` y `filter()`

Abre `index.html` para realizar el taller.
