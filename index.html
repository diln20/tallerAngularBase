4. Insertar en el array

agregarEstudiante() {
  const estudiante = {
    id: this.proximoId,
    nombre: this.nuevoEstudiante.nombre,
    correo: this.nuevoEstudiante.correo,
    edad: this.nuevoEstudiante.edad,
    activo: this.nuevoEstudiante.activo
  };

  this.estudiantes.push(estudiante);
  this.proximoId++;

  this.nuevoEstudiante = {
    nombre: '',
    correo: '',
    edad: 0,
    activo: true
  };
}

Mejorar el CRUD: usar id en vez de $index

🎯
Objetivo: identificar registros por su identidad estable, no por su posición temporal.
$index

Puede cambiar si eliminamos, ordenamos o insertamos elementos.

id

Identifica al registro aunque cambie su posición.

1. El hijo recibe id y lo emite

id = input.required<number>();

editar = output<number>();
eliminar = output<number>();
cambiarEstado = output<number>();

solicitarEditar() {
  this.editar.emit(this.id());
}

2. El padre escucha con $event

<app-tarjeta-estudiante
  [id]="estudiante.id"
  [nombre]="estudiante.nombre"
  [correo]="estudiante.correo"
  [edad]="estudiante.edad"
  [activo]="estudiante.activo"

  (editar)="editarEstudiante($event)"
  (eliminar)="eliminarEstudiante($event)"
  (cambiarEstado)="cambiarEstado($event)"
/>
emit(2)→$event = 2→editarEstudiante(2)

3. Buscar con find()

editarEstudiante(id: number) {
  const estudiante = this.estudiantes.find(
    estudiante => estudiante.id === id
  );

  if (!estudiante) {
    return;
  }

  // cargar sus datos
}

4. Eliminar con filter()

eliminarEstudiante(id: number) {
  this.estudiantes = this.estudiantes.filter(
    estudiante => estudiante.id !== id
  );
}
find()Encuentra un elemento.
filter()Crea una lista filtrada.
